Deep learning is a subfield of machine learning that uses artificial neural networks with many layers to learn representations of data at increasing levels of abstraction. The word "deep" refers to the number of layers through which data is transformed, as opposed to shallow models that use only one or two layers.

A typical deep learning model is built from layers of interconnected nodes, loosely inspired by neurons in the brain. Each layer receives input from the previous layer, applies a weighted transformation and a nonlinear activation function, and passes the result forward. During training, an algorithm called backpropagation calculates how much each weight in the network contributed to the model's error, and adjusts the weights slightly to reduce that error. This process is repeated across many examples until the network's predictions improve.

Deep learning has been especially successful in tasks involving images, audio, and text, domains where traditional machine learning struggled because useful features were difficult to hand-design. Convolutional neural networks, which apply small filters across an image to detect patterns like edges and textures, transformed computer vision. Recurrent neural networks, and later transformer architectures, transformed how machines process sequences of data such as sentences.

Training deep learning models typically requires large amounts of labeled data and significant computational power, often using specialized hardware called GPUs or TPUs to speed up the many matrix multiplications involved. A major risk in deep learning, as in machine learning generally, is overfitting, especially when a very large network is trained on a relatively small dataset. Techniques such as dropout, data augmentation, and early stopping are used to help the model generalize better to new data.
