Machine learning is a branch of computer science focused on building systems that improve their performance on a task through exposure to data, rather than through hand-written rules. Instead of a programmer specifying every step of a solution, a machine learning system is given examples and learns a pattern or function that generalizes to new, unseen inputs.

There are three broad categories of machine learning. Supervised learning trains a model on labeled examples, where each input is paired with a known correct output, such as predicting house prices from features like square footage and location. Unsupervised learning works with unlabeled data and tries to find hidden structure, such as grouping customers into segments based on purchasing behavior. Reinforcement learning trains an agent to make sequences of decisions by rewarding good outcomes and penalizing bad ones, commonly used in robotics and game-playing systems.

Common machine learning algorithms include linear regression, decision trees, support vector machines, and k-means clustering. Model performance is typically evaluated using a held-out test set that the model never saw during training, to check whether it generalizes rather than simply memorizing the training examples. Overfitting occurs when a model performs well on training data but poorly on new data, often because it is too complex relative to the amount of available data. Regularization techniques and cross-validation are commonly used to reduce overfitting.

Feature engineering, the process of selecting and transforming raw data into useful inputs for a model, was historically one of the most time-consuming parts of building a machine learning system. In recent years, deep learning approaches have reduced the need for manual feature engineering by learning useful representations directly from raw data.
